/* PURPOSE */

FET Web brings the power of automatic timetable generation
to the web browser. It is designed to help schools, colleges,
and universities create optimal schedules while respecting
complex constraints.

Features:
- Teacher, subject, and student management
- Room and building configuration  
- Flexible constraint system
- Automatic timetable generation
- Multiple view options (by teacher, student, room)
- Import/export compatibility with FET desktop
